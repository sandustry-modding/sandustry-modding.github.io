# Save and load

Opened from the [Pause menu](/okf/ui/pause.md).

## Save Game

Close X.
**SAVE NAME** textbox.
Empty name uses the placeholder (e.g. Save 21).
**OR OVERWRITE EXISTING**: name, age, Lv, playtime, credits, fluxite.
Confirm **Save** only when asked.

## Load Game

**Import .save**, close X.
Left **WORLDS** (name, level, save count, time, credits, fluxite).
Right: Factory Lv, **seed:**, **Copy seed**.
Tags **EXIT**, **QUICK**, **AUTO**.
**Load** / **Export** / **Delete** stay disabled until a row is selected.
