# OKF agent rules

OKF holds facts about the **shipping game** and its **public Sandkit** surface.
It does not hold template, kit, or third-party mod behavior.

Read [consume.md](/okf/consume.md) for load order and domain match.
Treat https://sandustry.com/sandkit.html as signature truth.

## New findings

Write each new vanilla fact into OKF before you finish the task that uncovered it.

1. Put the fact in the matching concept file under that domain.
2. When proof is missing, record the question in that domain's `gaps.md`.
3. Add a line to [log.md](/okf/log.md).

## Markdown

One sentence per line.
Exceptions: tables, fenced code, headings.
